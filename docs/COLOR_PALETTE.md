# Paleta de la interfaz

La interfaz usa una combinación de azul intenso, azul marino y blanco cálido. Los códigos son una adaptación para pantallas, no especificaciones oficiales de tintes. No se incorporan imágenes, escudos, patrones, nombres ni símbolos deportivos a la aplicación.

| Color | Código | Uso |
| --- | --- | --- |
| Azul intenso | `#0067D8` | Acciones, selección, gráficos y nuevos registros con color |
| Azul marino | `#142B55` | Navegación, texto y métricas destacadas |
| Blanco | `#FFFFFF` | Paneles, formularios y texto sobre azul |
| Blanco cálido | `#F7F6F2` | Superficies secundarias |
| Azul tenue | `#EAF2FE` | Avisos, etiquetas y estados suaves |
| Fondo claro | `#F4F7FC` | Área de trabajo |
| Texto secundario | `#536580` | Descripciones y cifras auxiliares |
| Foco | `#3B82F6` | Navegación por teclado |

Los tokens se centralizan en `apps/pwa/src/styles.css`. Los importes, operaciones y colores ya elegidos para tarjetas, cuentas, categorías y metas se conservan; los valores iniciales para nuevos registros usan azul. Las acciones destructivas se distinguen por su etiqueta, peso y subrayado; los errores incluyen un signo de exclamación y una franja, además del texto explicativo.

El icono existente de PaymentPlan solo cambia de color. La PWA instalada, favicon, manifiesto, gráficos y pantalla inicial de Android comparten los tonos.
